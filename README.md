# PRISM Companion

Prototipo di supporto al gioco di ruolo: i dadi restano fisici.

## Demo GitHub Pages
La cartella `docs/` è una demo autonoma. Multiplayer **simulato**, dati nella singola scheda del browser. Usa il pulsante in alto per passare tra Master e giocatore. Codice demo: DEMO2026. I valori sono esempi, non personaggi ufficiali.

## Multiplayer locale
Esegui `python3 server.py --host 0.0.0.0`, poi apri http://localhost:8765. Per dispositivi sulla stessa rete usa l’IP locale del computer server. Non esporre il server Python a Internet.

## Pubblicazione
Settings → Pages → Deploy from a branch → main → /docs. Nessun database o dato delle partite va caricato su GitHub.
